## 1. 왜 필요한가

현재 헤더 메뉴는 `어떻게 이용하나요(how-it-works)` · `관세(customs)` · `구매대행(purchase-agency)` · `로그인` · `회원가입` 다섯 개뿐이고, 사이트 어디에도 **"배송대행"이라는 이름의 메뉴/페이지가 없습니다.** USAJUSHO의 핵심 서비스가 배송대행(전송 서비스)인데 정작 그 이름의 진입점이 없고, 관련 정보가 세 곳에 흩어져 있습니다.

- 진행 순서(그림 설명) → `/how-it-works` 페이지에 있음 (7단계 일러스트, 이미 잘 만들어져 있음)
- 관세/면세한도/금지·제한 품목 → `/customs` 페이지에 있음 (매우 상세하게 이미 존재)
- 배송비 계산기 → 홈페이지 중간에 임베드되어 있음 (`FeeCalculator` 컴포넌트)
- FAQ → 홈페이지 하단에 일반적인 질문만 6개 있음 (배송대행 특화 질문은 부족)

콘텐츠 자체는 상당 부분 이미 존재하지만, **"배송대행 하나만 보고 싶은 손님"이 한 페이지에서 필요한 정보를 순서대로 보게 해주는 허브 페이지가 없는 상태**입니다. `/how-it-works`는 이번에 신규 페이지로 흡수되며 폐기됩니다 — 그 안의 진행순서 콘텐츠(7단계 일러스트)는 그대로 가져와서 재사용합니다.

## 2. 목표

- 헤더 메뉴에서 `어떻게 이용하나요`를 없애고 **"배송대행"** 항목으로 교체, 클릭 시 `/forwarding`으로 이동
- 손님이 "배송대행이 뭔지 → 어떤 순서로 진행되는지 → 보내기 전에 뭘 확인해야 하는지 → 얼마인지 → 궁금한 거 물어보기"까지 한 페이지 스크롤로 끝낼 수 있게 함
- 특히 "배송 전 확인사항"을 강하게 부각 — 관세를 물게 되는 금액 기준, 비타민처럼 개수 제한이 있는 품목을 미리 확인하지 않아 반송/폐기되는 사고를 사전에 줄이는 것이 목적

## 3. 정보 구조 (페이지 섹션 순서)

URL: **`/forwarding`**

1. **히어로 / 도입**
   - "배송대행이란?" 한 줄 정의 + 핵심 장점 3가지 (전용 미국주소, 합배송으로 절약, 100% 사진검수) — 기존 홈페이지 문구 재사용 가능
   - CTA: 무료로 시작하기 / 아래로 스크롤(배송비 계산하기)

2. **진행 순서 (그림으로 보기)**
   - 기존 `/how-it-works`의 7단계 일러스트(`step-illustrations.tsx`)를 그대로 이관 — 신규 제작 비용 없음
   - 단계: ① 회원가입 → 미국주소 발급 ② 미국 쇼핑몰에서 그 주소로 주문 ③ 창고 도착·사진검수 ④ 합배송/옵션 선택 ⑤ 일본으로 발송 ⑥ 트래킹 확인 ⑦ 일본 도착
   - `/how-it-works`가 없어지므로 이 섹션이 사실상 그 페이지의 유일한 후속 위치가 됨 — 내용 누락 없이 전부 이관

3. **배송 전에 꼭 확인하세요 (신규 제작 필요 — 핵심 섹션)**
   - "이것만은 미리 확인!" 체크리스트 형태로 3~4개 카드:
     - **관세/면세 한도**: 과세가격 1만엔 이하는 원칙적으로 면세 (개인 사용 목적은 해외 소매가의 60%로 계산 → 실제로는 약 16,600엔까지가 면세 기준). `/customs` 페이지의 상세 계산기로 링크
     - **개수 제한이 있는 품목**: 비타민/영양제는 개인사용 기준 합계 10kg 정도까지, 화장품류는 품목당 24개까지, 의약품은 2개월분까지 등 — `/customs` 페이지의 표를 요약해서 3~4줄로 보여주고 "전체 목록 보기" 링크
     - **발송 자체가 안 되는 품목**: 주류, 모조품, 생식품류, 총기·칼류 등 — 마찬가지로 요약 + 링크
     - **미국 카드가 없어도 되는 이유**: 구매대행 서비스 안내 + `/purchase-agency` 링크
   - 목적: 손님이 주문부터 하고 나서 "어? 이거 안 보내진대" 하고 당황하는 걸 미리 막는 것. 실제 데이터(관세율표, 품목별 제한)는 이미 `/customs` 콘텐츠에 다 있으므로 **새로 조사할 필요 없이 발췌/요약만 하면 됨**

4. **배송비 계산해보기**
   - 홈페이지에 있는 `FeeCalculator` 컴포넌트를 이 페이지에도 임베드 (같은 컴포넌트 재사용, 신규 개발 불필요)
   - 무게/박스 크기 입력 → 예상 배송비 + 관세 계산까지 한 번에

5. **요금 한눈에 보기 (선택 사항)**
   - 홈페이지의 "숨은 비용 없음" 배지 섹션(검수비 $0 · 입고비 $0 · 합배송비 $0)을 이 페이지에도 재노출 — 이미 만들어진 섹션이라 재사용만 하면 됨

6. **FAQ (배송대행 특화 — 일부 신규 작성 필요)**
   - 기존 홈페이지 FAQ 6개 중 배송대행 관련 항목(무료보관, 합배송, 인보이스, 파손/분실)은 재사용
   - 추가로 필요한 질문 예시:
     - 비타민/영양제도 계속 시켜도 되나요? 한도가 있나요?
     - 관세는 누가 언제 내나요?
     - 여러 번 주문한 걸 한 번에 합배송할 수 있나요? 기간 제한이 있나요?
     - 발송이 안 되는 물건을 실수로 주문하면 어떻게 되나요? (반송/폐기 비용 안내)
     - 배송 중 파손·분실되면 보상되나요?

7. **마무리 CTA / 문의**
   - 무료 회원가입 버튼
   - 문의: **일본어는 LINE 버튼, 영어는 이메일(info@usajusho.com) 안내** — 기존 홈페이지 Contact 섹션과 동일한 패턴, 새로 만들 것 없음

## 6. 필요한 사진·일러스트 리스트 (섹션별, 사이즈/스펙 포함)

두 종류로 나눠서 봐주세요.

- **일러스트**: 손으로 그린 듯한 SVG 라인 아트로, 코드로 직접 그리는 방식입니다. 기존 `/how-it-works`의 7단계 그림(`step-illustrations.tsx`)이 바로 이 방식이고, 네이비/틸 브랜드 컬러의 심플한 씬 일러스트입니다. **이건 제가 코드로 새로 그리면 되므로 별도로 사진을 구해오실 필요가 없습니다.**

**공통 가이드 (사진)**
- 밝고 깨끗한 화이트/라이트그레이 배경 톤 (브랜드 컬러: 네이비 `#1B2A4A`, 틸그린 `#2E6E6A`)
- 사진 안에 텍스트/글자를 넣지 말 것 (문구는 코드로 별도 overlay 처리)
- 실제 창고/실제 박스 사진일수록 좋음 — 스톡 이미지 느낌이 강하면 오히려 신뢰도가 떨어짐
- 파일명은 영문 소문자+하이픈으로 (`forwarding-warehouse-01.webp` 같은 식)

**공통 가이드 (일러스트)**
- 기존 `step-illustrations.tsx`와 동일한 화풍 유지: viewBox `0 0 200 160`, 배경 `var(--usj-surface)` 둥근 사각형, 선 색상은 `var(--usj-primary)`(네이비), 우측 상단에 `var(--usj-accent)`(틸) 색 스파클 배지
- 새 일러스트는 전부 제가 코드로 직접 제작 → 사진처럼 파일을 받을 필요 없음

**우선순위**: 사진은 없어도 페이지 배포 자체는 가능합니다 (일러스트로 전부 대체). 굳이 하나만 고르신다면 ②의 창고 실사 사진 1장이 가장 효과가 큽니다. 나머지는 나중에 준비되는 대로 하나씩 교체하면 됩니다.
